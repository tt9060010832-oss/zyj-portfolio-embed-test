# 张永杰 · 个人作品集网页预览版

完整收录 11 部 AI 作品和 16 部摄像作品。本次指定的 9 部 AI 和 11 部摄像视频使用桌面原文件，字节级保留，不转码、不压缩。其余 7 部维持先前的 720p 高码率版。封面和作品排序不变。

6 部 HEVC 原片默认按原格式播放；不兼容的设备可下载原片，或在播放错误提示中手动选择已有 720p 兼容版。不会自动降画质。所有 20 部原片均有下载入口。原片在发布时只做文件分片/拼接，SHA256 必须与桌面文件一致。

- Build Command：`node build.cjs`
- Publish Directory：`dist`
- Render 类型：Static Site

视频校验通过后复制到发布目录。无服务器进程、数据库或付费计算实例。
